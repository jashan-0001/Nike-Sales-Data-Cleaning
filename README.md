# Nike Sales Data Cleaning Project

## Project Overview
This project demonstrates how to clean a raw Nike sales dataset using Python and Pandas.

## Dataset
- Original Dataset: Nike_Sales_Uncleaned(1).csv
- Cleaned Dataset: Nike_Sales_Cleaned.csv

## Data Cleaning Steps
- Removed duplicate rows
- Handled missing values
- Standardized text formatting
- Converted data types
- Formatted dates
- Rounded numerical values
- Reset index
- Saved the cleaned dataset

## Technologies Used
- Python
- Pandas
- Visual Studio Code

## Output
The cleaned dataset contains:
- No missing values
- Standardized formatting
- Correct data types
- Ready for analysis
